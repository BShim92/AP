Check rules
  • Use the same units for the bet and coin values. For example, a 1.60 coin on a 0.80 bet counts as 2 bets. Empty cells count as zero.
  • Only the bottom two rows count. A wheel appears as a dot and adds when it’s in one of those rows. Use + Row to record a row above them.
  • Use Red ball to review for the separate placement checks. Enter its displayed coin value in the grid if it’s in a counted row.
